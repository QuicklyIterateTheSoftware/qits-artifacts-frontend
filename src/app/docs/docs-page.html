“Open” goes to that version's index.html on the docs wire. A version is published whole and evicted whole, and it is immutable — so a bundle URL never changes meaning under a reader: it serves the same bytes it did the day it was published, or it is gone and answers 404.

Branch and commit are what the publisher declared on the upload, not something this store verified. They are printed for you to match against a build and are deliberately not links: no row in this store records a commit, a run or a project.
